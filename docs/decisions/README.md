# Decision records

One file per decision that changes a protocol, model choice, budget,
interpretation, or governance rule. Numbered sequentially.

A decision record states what was decided, what it replaces, who decided it, and
what it does **not** authorize. Per `agents/README.md`, changes to the primary
research question, the final evaluation split, the spending cap, or the
deployment target must be recorded here.
